## 🚀 Getting Started

### 1. Development Server
Run the development server locally:
```bash
npm run dev
# or via command prompt:
cmd /c npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 2. Production Build
Create an optimized production build:
```bash
npm run build
```

### 3. Production Start
Run the production build:
```bash
npm run start
```
